Как работает система

Один экран. Слева — реестр (СЗ, закупки, договоры), справа — карточка. «Мои задачи» показывает только то, что ждёт именно вас.

Этапы: Потребность → Согласование СЗ → Расценка → Согласование → Договор → Исполнение → Закрыто.

  • Инициатор создаёт потребность из нескольких позиций (наименование, количество, единица). Цены он не указывает и не видит.
  • Руководитель подразделения согласует СЗ — целиком или отклоняя отдельные позиции.
  • Закупки (ОМТС) собирают позиции из разных СЗ в закупку (одинаковые — вместе), подбирают поставщика и цены: быстро (один поставщик) или через КП нескольких поставщиков со сравнением. Позицию можно разделить между поставщиками.
  • По сумме система сама выбирает коридор и согласующих (работают параллельно):

  • Закупки оформляют договор (по одному на поставщика; к рамочному — спецификация). Поставки и оплаты (траншами) приходят из 1С и разносятся по позициям — инициатор получает уведомление по своим позициям.
  • Лента решений неизменяемая: кто, когда, что решил. Записи «Система» — автоматические.

Сценарий для показа (переключайте пользователя в шапке «Вы:»):

  1. Серик Н. (инициатор КТЦ) → «+ Новая потребность», 2–3 позиции без цен → «Отправить».
  2. Бекетов А. (руководитель КТЦ) → «Мои задачи» → «✓ Согласовать».
  3. Оспанова А. (Закупки) → «Пул» → отметьте позиции → «Создать закупку» → в карточке «₸ Внести цены и поставщика».
  4. Ахметов Д.Б. (главный инженер) → «✓ Согласовать» (или «Согласовать все зелёные»). Для жёлтого/красного — ещё Финансы, Юристы, Гендиректор.
  5. Оспанова А. → «📄 Оформить договор» → в карточке договора «→ Подписан».
  6. Нурланова С. (Финансы) → в карточке договора «₸ Провести оплату» (30% / 50% / 100%).
